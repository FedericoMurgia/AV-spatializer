# Enclosure

Two 3D-printed parts. Sizes are the STL bounding boxes.

| File | Bounding size | Role |
|------|---------------|------|
| `av-spatializer-top.stl` | 217 × 157 × 26 mm | Top shell (was `AVmidicontroller.stl`) |
| `av-spatializer-bottom.stl` | 200 × 140 × 13.3 mm | Bottom (was `AVcontrollerbottom.stl`) |

The diffuser over the LED matrix is not printed: use frosted or opal acrylic
cut to the matrix window.
